# Similarity Explorer Support

Dieser Ordner enthaelt Alt- und Supportmodule, die nur noch fuer den separaten
`analysis_tools/similarity_explorer_app.py` oder fuer alte Similarity-/I-Relief-Auswertungen relevant sind.

Diese Dateien gehoeren nicht zur finalen App-Laufzeit und nicht zum finalen mRMR-/Boruta-Modell.
Sie bleiben erhalten, damit der Arbeitsverlauf und alte Analysepfade bei Bedarf nachvollziehbar bleiben.
